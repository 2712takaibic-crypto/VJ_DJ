### S001-R 起動安定性 / RealtimeChannel RTT

アプリを 100 回起動し、毎回ハンドシェイクが成立するかを確認。

| 項目 | 値 |
|---|---|
| 実行回数 | 100 |
| 成功 | **100** |
| 失敗 | **0** |
| 所要時間 | 383.5s (1 回あたり約 3.8s) |
| RTT p50 | 0.50 ms |
| RTT p95 | 2.30 ms |
| RTT p99 | 12.90 ms |
| RTT max | 17.70 ms |

再実行: `npm run build && npm run test:handshake`

**所見**: RTT の p50 は 0.5ms で、レンダラ直結の MessagePort として妥当。
p99 の 12.9ms と max の 17.7ms は 60Hz の 1 フレーム (16.7ms) 前後であり、
ハンドシェイクがフレーム境界を跨いだ場合の待ちと解釈できる。
ハンドシェイクは起動時 1 回きりで遅延要件がないため問題にならないが、
**プレビュー転送 (P1-20) で同様の分布が出た場合は 1 フレーム遅延の要因になる**ため、
PC002 の計測時にこの値を思い出すこと。
